# Darlight

Приложение для Windows 11: автоматически переключает светлую и тёмную тему
по расписанию.

- **Light** — днём, **Dark** — вечером и ночью; время настраивается
- Иконка в трее, ручное переключение, автозапуск при входе
- Тема применяется мгновенно, в том числе после пробуждения и разблокировки
- Русский и английский интерфейс

## Приватность

Darlight не собирает и не передаёт никаких данных — приложение вообще не
обращается к интернету. Все настройки хранятся локально на вашем компьютере.
