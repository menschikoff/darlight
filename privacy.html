Darlight — Политика конфиденциальности

Дата вступления в силу: 5 августа 2026

Коротко

Darlight не собирает, не передаёт и не хранит никаких персональных данных. Приложение вообще не обращается к интернету.

Какие данные обрабатываются

Приложение сохраняет только ваши настройки, и только на вашем компьютере:

ЧтоГде хранится
Включено ли автопереключение%LOCALAPPDATA%\Darlight\settings.json
Время начала светлой и тёмной темытам же
Выбранный язык интерфейсатам же
Включён ли запуск при входе в системутам же

Кроме того, приложение изменяет системные настройки темы текущего пользователя в реестре Windows:

  • HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize — собственно переключение светлой и тёмной темы;
  • HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run — запись для автозапуска, если вы его включили.

Эти данные не являются персональными и никуда не отправляются.

Чего приложение НЕ делает

  • не подключается к интернету и не передаёт данные на какие-либо серверы;
  • не собирает статистику, телеметрию и сведения об использовании;
  • не показывает рекламу;
  • не читает ваши файлы, переписку, историю браузера, буфер обмена;
  • не определяет ваше местоположение;
  • не передаёт ничего третьим лицам.

Внешние ссылки

В окне настроек есть ссылка «Поддержать разработчика». При нажатии открывается браузер со страницей платёжного сервиса Polar. Переход добровольный. На этой странице действует политика конфиденциальности Polar, а не наша; приложение не участвует в обработке платежа и не получает сведений о плательщике.

Удаление данных

Удалите папку %LOCALAPPDATA%\Darlight — это все данные, которые создаёт приложение. При удалении приложения через систему данные удаляются вместе с ним.

Важно: выбранная тема Windows (светлая или тёмная) сохранится и после удаления приложения — она остаётся такой, какой Darlight установил её в последний раз. Это сделано намеренно: менять оформление системы в момент удаления программы было бы неожиданным для пользователя. Сменить тему можно в любой момент вручную: «Параметры → Персонализация → Цвета».

Дети

Приложение не предназначено специально для детей и не собирает данные ни о ком.

Darlight — Privacy Policy

Effective date: 5 August 2026

In short

Darlight does not collect, transmit, or store any personal data. The application does not access the internet at all.

What data is processed

The application stores only your settings, and only on your computer:

WhatWhere
Whether auto-switching is enabled%LOCALAPPDATA%\Darlight\settings.json
Light and dark start timessame file
Selected interface languagesame file
Whether to run at Windows startupsame file

The application also changes the current user's Windows theme settings in the registry:

  • HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize — the light/dark theme switch itself;
  • HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run — the autostart entry, if you enabled it.

This data is not personal and is never sent anywhere.

What the application does NOT do

  • does not connect to the internet or send data to any server;
  • does not collect analytics, telemetry, or usage data;
  • does not display advertising;
  • does not read your files, messages, browser history, or clipboard;
  • does not determine your location;
  • does not share anything with third parties.

External links

The settings window contains a “Support the developer” link. Clicking it opens your browser at a payment page hosted by Polar. Following the link is voluntary. That page is governed by Polar's privacy policy, not ours; the application takes no part in processing the payment and receives no information about the payer.

Deleting your data

Delete the folder %LOCALAPPDATA%\Darlight — that is all the data the application creates. Uninstalling the application removes this data as well.

Please note: your Windows theme setting (light or dark) remains after the application is uninstalled — it stays exactly as Darlight last set it. This is deliberate: changing your system appearance at the moment you remove a program would be unexpected. You can change it at any time in Settings → Personalization → Colors.

Children

The application is not directed at children and collects no data about anyone.

Changes

If this policy changes, the date at the top of this document will be updated.
